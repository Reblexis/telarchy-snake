# telarchy-snake

A snake game steered by a Telarchy workspace: three proposals a minute
(turn left, turn right, continue), the market prices each on the longest
the snake will have been this game in 60 moves, the highest impact is
approved and the snake moves. `docs/snake.md` governs; the code exists
to satisfy it.

Live workspace: https://telarchy.com/snake. Board: https://snake.telarchy.com. Stream: https://www.twitch.tv/telarchy.

```bash
npm install
npm test
cp .env.example .env   # fill in
npm run dev
```
