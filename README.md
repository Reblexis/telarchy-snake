# telarchy-snake

A snake game steered by a Telarchy workspace: four proposals a minute, one
per direction, the market prices each on the snake's length, the highest
is approved and the snake moves. `docs/snake.md` governs; the code exists
to satisfy it.

Live workspace: https://telarchy.com/snake (once running).

```bash
npm install
npm test
cp .env.example .env   # fill in
npm run dev
```
